# FER2013 Dataset

This project uses the FER2013 (Facial Expression Recognition 2013) dataset for training and evaluation of facial emotion recognition.

## Dataset Information

- **Dataset:** FER2013
- **Image Size:** 48 × 48 pixels
- **Color Format:** Grayscale
- **Emotion Classes (7):**
  - Angry
  - Disgust
  - Fear
  - Happy
  - Sad
  - Surprise
  - Neutral

## Download

The dataset can be downloaded from Kaggle:

https://www.kaggle.com/datasets/msambare/fer2013

## Note

The complete dataset is **not included** in this repository due to its size and licensing considerations. Please download it from the official source using the link above.
